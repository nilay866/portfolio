- **21 FortiGate Firewalls**: BGP AS 65000 ADVPN Full-Mesh overlay, IPsec hub-and-spoke topologies, HA cluster failover, and strict zero-trust zone segmentation.
- **Enterprise SOC & Threat Defense**: Wazuh SIEM agent fleet, real-time Syslog aggregation, brute-force mitigation, and IOC hunting.
- **Virtualization & Automation**: Linux KVM / QEMU enterprise clusters, custom bash automation scripts, and automated configuration backups.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/nilay866/portfolio.git
cd portfolio

# Install dependencies
npm ci

# Start the development server
npm run dev

# Build for production
npm run build
```
