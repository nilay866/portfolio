1. Executive Summary & Production Scope

Cinépolis India operates high-throughput multi-screen cinema complexes processing thousands of customer ticketing transactions daily. The on-premise infrastructure at each location requires 99.9% platform availability across Point-of-Sale (POS) ticketing terminals, automated kiosk networks, administrative management workstations, digital cinema projection servers, and high-density CCTV surveillance networks.

Production Responsibilities: As IT & Platform Support Associate, Nilay Chavhan was directly responsible for:

  • Centralized administration of Windows Server 2022 Active Directory Domain Services (AD DS), Organizational Units (OUs), Group Policy Objects (GPOs), and internal DNS/DHCP scopes supporting 100+ endpoints.
  • Layer 2/3 network segmentation across Aruba enterprise switches, isolating sensitive payment POS subnets from guest Wi-Fi and CCTV traffic.
  • Edge firewall traffic shaping and Quality of Service (QoS) enforcement, ensuring transactional ticketing APIs received strict bandwidth priority over bulk web browsing.
  • Primary leased-line circuit fault diagnosis and vendor coordination with telecom ISPs (Airtel, Tata Tele) to restore fiber links within strict 4-hour MTTR penalty windows.

3. Active Directory & Systems Administration

  • AD DS & OU Hierarchy: Organized domain objects into structured Organizational Units (OU=POS_Terminals, OU=BoxOffice_Staff, OU=Cinema_Servers).
  • Group Policy Object (GPO) Deployment: Enforced security baselines, USB mass-storage restrictions on POS kiosks, automated desktop lockouts, and scheduled background patch updates.
  • DHCP & DNS Architecture: Configured Windows Server DHCP scopes with 8-hour lease durations for dynamic terminals and reserved static bindings for network printers and payment pin-pads.
  • Disaster Recovery Drills: Executed monthly scheduled system state backup restorations ensuring zero data loss in case of hardware storage corruption.

4. Production Incidents & Operational Resolutions

Incident: POS Terminal Duplicate IP Conflict during Peak Weekend Box-Office

Symptom: Box-office terminal #4 suddenly lost database connectivity to the central ticketing server 30 minutes before movie showtime, throwing transaction timeout errors.
Investigation: Executed arp -a on the local gateway and discovered two distinct MAC addresses flapping on IP 192.168.20.14. A newly deployed handheld concession scanner had been statically assigned an IP falling within the active dynamic DHCP pool.
Remediation: Reconfigured the DHCP server to exclude static reservation ranges (192.168.20.1 to 192.168.20.50), assigned the scanner a dedicated DHCP reservation, and issued ipconfig /release && ipconfig /renew on the box-office terminal. Uptime restored in under 8 minutes.
